# 🍽️ Online Yemek Tarifi Sitesi

Bu proje, farklı dünya mutfaklarından lezzetli yemek tariflerini bir araya getiren
basit ve kullanıcı dostu bir web sitesidir.

## 🚀 Özellikler
- Dünya mutfaklarından tarifler
- Basit ve şık arayüz
- HTML, CSS ve JavaScript kullanımı

## 🛠️ Kullanılan Teknolojiler
- HTML5
- CSS3
- JavaScript
